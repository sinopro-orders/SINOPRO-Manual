# 2-1. 경고 표지 및 기호 설명

{% hint style="danger" %}
**위험 (DANGER)** — 지시를 따르지 않을 경우 사망 또는 중상으로 이어질 수 있는 임박한 위험 상황을 나타냅니다.
{% endhint %}

{% hint style="warning" %}
**경고 (WARNING)** — 지시를 따르지 않을 경우 사망 또는 중상으로 이어질 수 있는 잠재적 위험 상황을 나타냅니다.
{% endhint %}

{% hint style="info" %}
**주의 (CAUTION)** — 지시를 따르지 않을 경우 경상 또는 장비 손상으로 이어질 수 있는 상황을 나타냅니다.
{% endhint %}
